Timeline 2.0 Guide

Timeline 2.0 replaces the old window with a new one built around three editors: a Dope Sheet for timing, a Graph for curves, and an NLA for layering clips. ShalltyUtils' tools are now part of Timeline, in the normal menus. Old scenes open as they are.

  • Open Ctrl+T or the Timeline button in Studio
  • Play / pause Shift+T, or Space over the window
  • Games KK · KKS · AI · HS2

No game at hand? Try the window right here: a working copy runs in this page, with a sample scene and a list of things to try.

01The window

Everything sits in one window you can drag by its header. Keys only work while the mouse is over it; everywhere else the keyboard belongs to Studio and the other plugins. Right-click anything for a menu: keys, the ruler, tracks and strips all have one.

  1. 1Editor. Switch between Dope Sheet, Graph and NLA. The menus next to it change with the editor.
  2. 2Menus. View, Select, Key, Channel and Marker; in the NLA, Strip and Add. Every tool is here or in a right-click menu, two clicks at most.
  3. 3Toggles. Motion path, Snap, Theme, Properties, Undo, Redo, the ⋯ menu, and × to hide the window. The Graph adds Handles and Normalize.
  4. 4Transport. Start, previous key, play, next key, end, then the playhead time. Click the length after it to change the scene length and playback speed.
  5. 5◆ Key. Keys the selected tracks at the playhead, or the node selected in the scene (I). The ▾ keys only part of the node: position, rotation or scale, one axis if you like.
  6. 6Tracks. ＋ Add adds tracks for what is selected in the scene, the search box filters them, and ◎ shows only what is selected in the scene. Tracks sit under their character and can be grouped; View › List tracks lists them by object or as grouped (see Tools). The eye shows a track in the Graph; the lock stops edits.
  7. 7Ruler. Click or drag to move the playhead. Markers sit on it (M adds one). Ctrl+drag marks a range to trim.
  8. 8Keys. Click to select, Ctrl+click to add, drag empty space to box select, drag a key to move the selection. The top rows sum up the keys of the character and of each group.
  9. 9Playhead. Where new keys go, and where paste lands.
  10. 10Properties. Tabs for the selected key, track or strip: time, value, interpolation, key type, and a small graph of the curve around the key. It can pop out into its own window.
  11. 11Status bar. What the mouse and keys do where the pointer is, and how many keys are selected.

02A first animation

Five steps from an empty timeline to a movement that plays.

  1. Select what should move.

    Click a character's IK or FK node, or any item, in the scene as you normally would in Studio.

  2. Key it.

    Press ◆ Key or I with the mouse over the window. Timeline makes the tracks it needs, puts them under the character, and keys them at the playhead.

  3. Move the playhead.

    Click the ruler at 2 s, or press → to go frame by frame.

  4. Change the pose and key again.

    Drag the node in the scene, then press ◆ Key. To skip this step, turn on ⋯ › Record live changes: while paused, whatever you change gets a key at the playhead; while playing, your movement is recorded as it happens.

  5. Play it.

    Press Space. To smooth the motion, select the keys and pick an interpolation in the Properties sidebar or under Key › Interpolation.

03Three editors

The same tracks in three views. Switch with the editor button at the top left.

Dope Sheet

Keys as diamonds on rows. Use it for timing: moving, copying and spacing keys, and for markers.

View · Select · Key · Channel · Marker

Graph

The values as curves. Drag a key to change time and value; hold Ctrl for time only or Alt for value only. Drag handles to shape Bézier curves. Normalize fits every curve to the same height.

View · Select · Key · Channel

NLA

Clips of animation as strips on lanes, layered and blended. Use it to reuse a movement, repeat it, or put one on top of another.

View · Select · Strip · Add

04Keys and curves

Interpolation

How the value travels from one key to the next. Each card plays 48 frames through three keys, and the ball above it sits where the value is: it glides where the curve is smooth and jumps where it steps. Set it in the Properties sidebar or Key › Interpolation. Key › Handle type sets it for one side of a key only.

Key types

A key type changes how a key looks, not how it moves. It helps you read a busy sheet at a glance.

TypeUse it for
KeyframeAn ordinary key. Every key from before 2.0 is one.
BreakdownA pose between two others, there to shape the transition.
Moving holdA pose held on purpose, so the motion stops instead of drifting through it.
ExtremeThe furthest point of a motion: the top of a jump, the end of a swing.
JitterNoise laid on top of a motion that is already finished.

Snapping

The Snap button picks what dragged keys and strips land on. Hold Shift while dragging to turn snapping off for that drag, or on when Snap is Off. In every mode except Off, a marker close by wins.

Cleaning up

  • Key › Simplify throws away keys that add nothing, lightly, moderately or strongly.
  • Key › Remove repeated keys, in every track deletes keys that only repeat the value before them.
  • Key › Snap selected keys to frames, Smooth selected keys and Flatten their handles tidy a selection in one go.
  • Key › Give the selected keys this key's value, Reset to the default value, Add / subtract… and Randomize… change many values at once.

05NLA

The NLA works like Blender's. Each character or item has its own stack of lanes. Strips on the lanes play clips, and the stack is read from the bottom up: rest values first, then each lane, then the Keys row on top.

  • Make a clip. Select tracks and use Channel › Push down to strip. Their keys become a clip, and a strip for it lands on a new lane at the top of the stack.
  • The Keys row holds keys that are not in a strip yet. It plays over the lanes; right-click it to set how it blends and its influence.
  • Blend decides how a strip meets what is under it: Replace takes over, Add puts its movement on top, Subtract takes it away, Multiply scales it.
  • Influence fades a strip in or out. Select a strip, press ◆ Key influence in Properties, move the playhead, change Influence: the strip fades, and a line across it draws the fade.
  • Edit clip keys opens a strip's keys in the Dope Sheet and Graph. Press Done editing clip keys in the header to put them back.
  • Duplicate linked (Shift+D makes a plain copy) shares one clip between strips, so editing one changes all. Make single user gives a strip its own copy again.
  • Lanes can be renamed, muted, soloed and locked. Y splits the active strip at the playhead. Shift+click adds strips to the selection, and Ctrl+click toggles individual strips. Move, duplicate, mute, or delete the selection together.

09Compatibility

Scenes

Scenes and timeline files from older versions open as they were, including the strips, Keyframe Groups, Picker pages and rigs that ShalltyUtils saved. Groups load exactly as saved, a group holding tracks of several objects included, and saving with 2.0 keeps them so the old Timeline still reads them the same way.

Remove ShalltyUtils before installing. Timeline 2.0 will not load next to it. BepInEx then skips Timeline and logs “Could not load [Timeline] because it is incompatible with: com.shallty.shalltyutils”, and ShalltyUtils fails too, since it needs Timeline.

Other plugins

Plugins that add tracks through Timeline's API keep working: Graphics, FaceExpress, SliderCH, NodesConstraints and the pose editors all load their tracks. If a plugin seems missing from ＋ Add, pick something in its own window first.

The Bird of Hermes is now part of Timeline. Remove its standalone DLL when installing Timeline 2.0. Add-ons that access private fields from the Classic window may need updates.

For add-on authors

Use the public API rather than private fields, and reach anything else through reflection so a missing member costs a feature instead of your whole UI:

  • Timeline.MainWindowRectTransform: the window, for placing things next to it. Read its corners with GetWorldCorners, since the pivot and scale differ from 1.x.
  • Timeline.playbackTime, isPlaying, duration, Play(): playback state.
  • TimelineCompatibility in ToolBox: registering interpolables, as before.
